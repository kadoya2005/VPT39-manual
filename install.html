VPT39 インストール方法

Windows のPC で、はじめて VPT39 を使えるようにするまで（PC ごとに最初の1回だけ）

必要なもの Windows 11 のPC（64bit。Windows 11 で動作を確認しています）、インターネット、30分ほどの時間。
すでに入っているもの（Python・VLC）は飛ばしてかまいません。

1VPT39 をダウンロードする

  1. ブラウザで https://github.com/kadoya2005/VPT39 を開く
    GitHub（ギットハブ）というサイトの、VPT39 のページです。アカウントの登録やログインはいりません。
  2. 緑の「Code」ボタン →「Download ZIP」をクリック
    「VPT39-main.zip」がダウンロードされます（「ダウンロード」フォルダに入ります）。
「Releases」の v1.0 の ZIP は使わないでください v1.0 の ZIP は、setup.bat が文字化けして動かない古い形のままです。かならず上の「Code」→「Download ZIP」から取ってください。
ほかの人から VPT39_配布用.zip を受け取った場合 その ZIP を使ってかまいません。②から進めてください（展開してできるフォルダの名前が「VPT39」になります）。

2ZIP を展開する

  1. （おすすめ）ZIP の「ブロック」を外す
    VPT39-main.zip を右クリック →「プロパティ」→ 下のほうの「セキュリティ：このファイルは他のコンピューターから取得したものです…」の「許可する」にチェック→「OK」。
    これをしておくと、あとで setup.bat などを実行するたびに出る警告が出なくなります。「許可する」の欄がなければ、そのまま次へ。
  2. ZIP を右クリック →「すべて展開」→「展開」
    「VPT39-main」というフォルダができます。デスクトップやドキュメントなど、好きな場所に移してかまいません。フォルダの名前を「VPT39」に変えてもかまいません。
ZIP の中から直接開かない ZIP をダブルクリックして中をのぞいた状態で setup.bat を実行しても、動きません。かならず「すべて展開」してから、展開したフォルダの中で実行します。
置き場所について Dropbox や OneDrive の中に置いても動きます。ただし本番では、素材の動画がPC にダウンロード済みになっていることを確かめてください（「オンラインのみ」のファイルは、読み込みに時間がかかります）。

3Python を入れる

VPT39 は Python（パイソン）というプログラムの上で動きます。

Python は「3.13」を選ぶ python.org のいちばん上にある最新版（3.14 以降）では、Spout（TouchDesigner などから映像を受け取る機能）の部品が入りません。VPT39 は Python 3.13（64bit）で確かめています。
Python が入っているか分からないときは いったん飛ばして⑤の setup.bat を実行してみてください。入っていなければ「失敗：Python が見つかりません」と出るので、そのときここに戻ります。
  1. https://www.python.org/downloads/windows/ を開く
    「Python 3.13.〇〇」の見出しを探し、その下の Download Windows installer (64-bit) をクリックします。〇〇の数字は、いちばん大きいもの（上にあるもの）でかまいません。
  1. ダウンロードした「python-3.13.〇〇-amd64.exe」をダブルクリック
  2. 最初の画面で、下の「Add python.exe to PATH」にチェック →「Install Now」
    ここがいちばん大事です。チェックを忘れると、setup.bat が Python を見つけられません（最初はチェックが空いています）。
  1. 「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」
  2. 「Setup was successful」と出たら「Close」
    途中に出る「Disable path length limit」は、押しても押さなくてもかまいません。
チェックを忘れたときは もう一度 python-3.13.〇〇-amd64.exe を実行し、「Modify」→「Next」→「Add Python to environment variables」にチェック →「Install」。または、いったんアンインストールして入れ直します。

4VLC を入れる

VLC（ブイエルシー）は無料の動画プレイヤーです。VPT39 は、動画の音を出すのに VLC の部品を使います。

  1. https://www.videolan.org/vlc/ を開き、オレンジの「Download VLC」をクリック
    Windows のPC で開くと、64bit 版が自動で選ばれます。
  2. ダウンロードした「vlc-〇〇-win64.exe」を実行
    言語は「日本語」→ あとは「次へ」を押していき、「インストール」→「完了」。設定は変えなくてかまいません。
VLC がないと 動画は映りますが音が出ません。起動したあと、操作パネル左上に「VLC（音声あり）」と出ていれば正常です。「OpenCV（音声なし）」と出ていたら、VLC が入っていません（または 32bit 版が入っています）。

5setup.bat を実行する

  1. 展開したフォルダの中の「setup.bat」をダブルクリック
    黒い画面が開き、[1/4]〜[4/4] の順に進みます。部品のダウンロードがあるので 2〜5分かかります。文字が流れている間は、閉じずに待ちます。
  2. 「成功しました」と出たら、何かキーを押して閉じる
青い警告や確認が出たら 「Windows によって PC が保護されました」→「詳細情報」→「実行」。
「発行元を確認できませんでした。このソフトウェアを実行しますか？」→「実行」。
（②で「許可する」にチェックしておくと出ません）
setup.bat は何度実行してもだいじょうぶ 失敗したときは、原因を直してからもう一度実行します。入れ終わった部品は飛ばして、続きから入ります。

6run.bat で起動する

  1. 「run.bat」をダブルクリック
    黒い出力ウィンドウ（VPT39 出力1）と、ブラウザの操作パネルが開けば成功です。
    操作パネルが開かないときは、ブラウザで http://localhost:8080/ を開きます。
  2. 初回だけ「Windows セキュリティの重要な警告」が出たら「許可」
    スマホやタブレットから操作するための通信の確認です。「プライベート ネットワーク」にチェックして「アクセスを許可する」を押します。
ファイルいつ使う
run.batふだんの起動。前回フルスクリーンにした出力は、同じ画面にフルスクリーンで開く
run_window.batその回だけ、全部の出力をウィンドウで開く（準備・リハ用。設定は書き換えない）
setup.batはじめての準備（上の⑤）。ふだんは使わない
次からは run.bat をダブルクリックするだけです。デスクトップにショートカットを作っておくと便利です（run.bat を右クリック →「その他のオプションを確認」→「ショートカットの作成」）。

ここから先の使い方は、クイックスタート・詳細ガイド・画面対応マニュアルを見てください。

7うまくいかないとき

setup.bat は、最後に必ず「成功しました」か「失敗：〜」のどちらかを出して止まります。失敗したときは、出た文字に合わせて直し、もう一度 setup.bat を実行します。

出た文字・起きたこと原因と直し方
失敗：Python が見つかりませんPython が入っていない、または「Add python.exe to PATH」のチェック忘れ。③をやり直す。Python を入れた直後は、開いていた黒い画面を閉じてから setup.bat を実行し直す
Microsoft Store が開いたPython が入っていない状態です。Store からは入れずに閉じて、③の手順（python.org）で入れる
失敗：部品を入れられませんでしたインターネットにつながっていない（学校や会社のネットワークで止められていることも）。別の回線（スマホのテザリングなど）で試す。Python が 3.14 以降だと、部品の対応版がまだないことがある → Python 3.13 を入れて、展開したフォルダの中の .venv フォルダを消してから setup.bat をやり直す。それでもだめなら、赤い ERROR の行を写真に撮って相談
（注意）この Python では Spout が使えません失敗ではなく注意です。準備は続きます。Spout を使わないならそのままでかまいません
黒い画面が文字化けして「'sys' は、内部コマンドまたは外部コマンド…」がたくさん出る古い形の ZIP（v1.0 のリリースなど）です。①の「Code」→「Download ZIP」から取り直す
黒い画面が一瞬で消えるZIP の中から直接開いている。②の「すべて展開」をしてから実行する
動画の音が出ない（「OpenCV（音声なし）」と出る）VLC が入っていない、または 32bit 版。④で 64bit 版を入れて、VPT39 を起動し直す
出力ウィンドウが真っ黒のまま・すぐ落ちるグラフィックのドライバーが古い可能性があります。PC メーカーや Intel・NVIDIA・AMD のサイトから最新のドライバーを入れる
相談するときは 黒い画面の赤い文字の部分と、Python のバージョン（黒い画面の [1/4] の下に出る「Python 3.〇〇」）がわかる写真を送ってください。

8新しい版に入れ替えるとき

  1. 今のフォルダから、自分のものを控えておく
    media（素材）、photos（写真）、settings（会場ごとの設定）、project.json（今の設定）。
  2. ①②の手順で新しい版をダウンロードして展開する
  3. 控えておいたものを、新しいフォルダにコピーする（同じ名前のものは上書き）
  4. 新しいフォルダで setup.bat を実行する（Python と VLC は入れ直さなくてかまいません）
本番の直前には入れ替えない 新しい版は、本番の前にかならずリハで確かめてください。前の版のフォルダは、しばらく消さずに残しておくと安心です。
