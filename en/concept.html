How VPT39 Works

The picture flows in this order: "Media → Layers → Outputs → Screen"

About this app: A video player made for projection mapping.
It is designed to be easy to use for media and interactive art with projectors, live shows and more.
VPT39 is an unofficial tool inspired by VPT (VideoProjectionTool) by HC Gilje. It is not affiliated with VPT in any way.

1How the picture reaches the screen

2There are two screens

Do everything on the laptop's control panel. The output window only shows it (fullscreen, to the audience). Corners can also be set from a phone on the same Wi-Fi.

3Switch for each song (Play column)

Put each song's clips at the same number (column). One press of "Play column 2" then switches every layer to song 2.

4Fit the shape (mapping)

Drag each layer's four corners to fit a slanted screen. Saved as ratios, so it holds at any resolution.

5Transitions (crossfade)

Press a clip and picture and sound change smoothly together. Set the time with the layer's "Fade" (0 = instant).

6How sound flows

All layers' sound plays at the same time. BLACKOUT and "Hidden" affect only the picture, not the sound.

Setting up inputs and outputs, and features that help in the show

8Kinds of media (inputs)  — all are clips you arrange and switch the same way

9Ways to set up outputs (projectors)

10Photo wall

8 transition types (fade / cut / slide / wipe / zoom). Put media images in the row and they show in that order (a single image stays on).

11Align from a phone

Stand in front of the screen with your phone and use the arrow pad to move 1 px at a time (hold to repeat). You can adjust while watching the screen. (Open it with "Phone" in the top bar → QR code)

12Words used

ClipOne media item to play (any kind in 8)
LayerA level for stacking pictures. L1 is at the back
OutputThe picture for one projector
FullscreenThe output window fills the display
MappingMoving the four corners to fit the shape
BLACKOUTDarkens only the picture (the sound stays)
Edge blendSoftly overlapping the seam of a wide picture

Test media"テスト用" in media and photos. For checking motion and sound
