Installing VPT39

How to get VPT39 running on a Windows PC for the first time (once per PC)

What you need A Windows 11 PC (64-bit; VPT39 is tested on Windows 11), an internet connection, and about 30 minutes.

1Download VPT39

  1. Open https://github.com/kadoya2005/VPT39 in your browser
    This is the VPT39 page on GitHub. You do not need an account or to sign in.
  2. Click the green "Code" button → "Download ZIP"
    "VPT39-main.zip" is saved to your Downloads folder.
Do not use the v1.0 ZIP under "Releases" In the v1.0 ZIP, setup.bat is in an old format that shows garbled text and does not work. Always use "Code" → "Download ZIP" above.
If someone gave you VPT39_配布用.zip You can use that ZIP. Start from step 2 (the extracted folder is called "VPT39").

2Extract the ZIP

  1. (Recommended) Unblock the ZIP
    Right-click VPT39-main.zip → "Properties" → near the bottom, at "Security: This file came from another computer…", check "Unblock" → "OK".
    This stops the warning that appears each time you run setup.bat and the other files. If there is no "Unblock" box, just go on.
  2. Right-click the ZIP → "Extract All" → "Extract"
    A folder called "VPT39-main" is created. You can move it anywhere (Desktop, Documents…) and rename it to "VPT39".
Do not run files from inside the ZIP If you double-click the ZIP and run setup.bat from the preview, it will not work. Always "Extract All" first, then run it inside the extracted folder.
Where to put it It works inside Dropbox or OneDrive too. For a show, make sure your videos are downloaded to the PC ("online-only" files load slowly).

3Install Python

VPT39 runs on Python.

Choose Python "3.13" With the newest version at the top of python.org (3.14 or later), the Spout component (for receiving video from TouchDesigner and others) cannot be installed. VPT39 is tested with Python 3.13 (64-bit).
Not sure if Python is installed? Skip ahead and run setup.bat (step 5). If Python is missing, it says "Failed: Python not found" — then come back here.
  1. Open https://www.python.org/downloads/windows/
    Find the heading "Python 3.13.xx" and click Download Windows installer (64-bit) under it. If there are several 3.13 versions, take the highest number (the one nearest the top).
  1. Double-click the downloaded "python-3.13.xx-amd64.exe"
  2. On the first screen, check "Add python.exe to PATH" at the bottom → "Install Now"
    This is the most important step. Without the check, setup.bat cannot find Python (the box is empty at first).
  1. If asked "Do you want to allow this app to make changes to your device?", click "Yes"
  2. When "Setup was successful" appears, click "Close"
    "Disable path length limit" is optional.
Forgot the check? Run python-3.13.xx-amd64.exe again → "Modify" → "Next" → check "Add Python to environment variables" → "Install". Or uninstall Python and install it again.

4Install VLC

VLC is a free video player. VPT39 uses VLC's components to play the sound of videos.

  1. Open https://www.videolan.org/vlc/ and click the orange "Download VLC" button
    On a Windows PC, the 64-bit version is chosen automatically.
  2. Run the downloaded "vlc-xx-win64.exe"
    Choose your language, then click "Next" through to "Install" → "Finish". You do not need to change any settings.
Without VLC Videos play but without sound. After starting VPT39, the top left of the control panel shows "VLC (audio)" when it is fine. If it shows "OpenCV (no audio)", VLC is missing (or the 32-bit version is installed).

5Run setup.bat

  1. Double-click "setup.bat" in the extracted folder
    A black window opens and goes through [1/4] to [4/4]. It downloads components, so it takes 2–5 minutes. Do not close it while text is scrolling.
  2. When it says "Success", press any key to close it
If a blue warning or a question appears "Windows protected your PC" → "More info" → "Run anyway".
"The publisher could not be verified. Are you sure you want to run this software?" → "Run".
(These do not appear if you checked "Unblock" in step 2.)
You can run setup.bat as many times as you like If it fails, fix the cause and run it again. It skips what is already installed and continues.

6Start with run.bat

  1. Double-click "run.bat"
    If a black output window and the control panel in your browser open, it worked.
    If the control panel does not open, open http://localhost:8080/ in your browser.
  2. The first time only: if "Windows Security Alert" appears, allow it
    This is for controlling VPT39 from a phone or tablet. Check "Private networks" and click "Allow access".
FileWhen to use it
run.batNormal start. Outputs that were fullscreen last time open fullscreen on the same screen
run_window.batOpens all outputs as windows this time only (for preparing and rehearsing; settings are not changed)
setup.batFirst-time setup (step 5). Not needed day to day
From now on Just double-click run.bat. A desktop shortcut is handy (right-click run.bat → "Show more options" → "Create shortcut").

For how to use VPT39, see the Quick start, the Guide and the Screen-by-screen manual.

7If something goes wrong

setup.bat always stops with either "Success" or "Failed: …" at the end. If it fails, fix the cause shown and run setup.bat again.

What you seeCause and fix
Failed: Python not foundPython is not installed, or "Add python.exe to PATH" was not checked. Redo step 3. After installing Python, close any open black windows before running setup.bat again
The Microsoft Store opensPython is not installed. Close the Store and install Python from python.org (step 3)
Failed: could not install the componentsNo internet connection (school or office networks may block it) — try another connection such as phone tethering. With Python 3.14 or later, some components may not be available yet → install Python 3.13, delete the .venv folder in the extracted folder, and run setup.bat again. If it still fails, take a photo of the red ERROR lines and ask
(Note) Spout does not work with this PythonThis is a note, not a failure. Setup continues. If you do not use Spout, you can ignore it
Garbled text and many "'sys' is not recognized as an internal or external command…"You have the old-format ZIP (such as the v1.0 release). Download again with "Code" → "Download ZIP" (step 1)
The black window closes instantlyYou are running it from inside the ZIP. "Extract All" first (step 2)
No sound ("OpenCV (no audio)" is shown)VLC is missing or is the 32-bit version. Install the 64-bit VLC (step 4) and restart VPT39
The output window stays black or closes right awayThe graphics driver may be old. Install the latest driver from your PC maker or from Intel, NVIDIA or AMD
When asking for help Send a photo showing the red text in the black window and your Python version (the "Python 3.xx" line under [1/4]).

8Updating to a new version

  1. Keep your own files from the current folder
    media (your media), photos (photos), settings (venue settings), project.json (current settings).
  2. Download and extract the new version (steps 1 and 2)
  3. Copy the files you kept into the new folder (overwrite files with the same name)
  4. Run setup.bat in the new folder (no need to reinstall Python or VLC)
Do not update just before a show Always check a new version in a rehearsal first. Keeping the old folder for a while is a good idea.
