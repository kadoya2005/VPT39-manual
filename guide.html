1VPT39 でできること

VPT39 は、ノートPC 1台で動画や写真をプロジェクターに映し、スクリーンや壁の形に合わせるためのアプリです。VPT（VideoProjectionTool）の「四隅マッピング」と、VJアプリのように「クリップを並べて切り替える」操作を組み合わせています。

できること内容
クリップ再生動画や画像をサムネイルで並べ、クリックで切り替え。前の映像からなめらかに入れ替わる（クロスフェード）
列で再生同じ番号のクリップを、全部のレイヤーで一斉に切り替え。曲ごとに映像をまとめて変えられる
レイヤー映像を何枚でも重ねられる。重ね方（通常・加算・スクリーン・乗算）と不透明度を選べる
マッピングレイヤーごとに四隅を動かして、台形や斜めのスクリーンにぴったり合わせる
複数出力プロジェクターを何台でも使える。レイヤーごとに、どのプロジェクターに映すか選ぶ（同じ映像を複数に同時にも）
横長の画面2台以上のプロジェクターをつないで1枚の横長の映像に。重なりはぼかしてつなぐ
ライブ入力カメラ・キャプチャーボード（別のPCの画面と音）や、同じPCのウィンドウ（Zoom など）を映す
レイヤー映像あるレイヤーの映像を、同じタイミングで別の場所・別の出力にも映す
音声ミキサー全部の動画の音を同時に鳴らし、出力ごと・レイヤーごとに音量とミュートを調整
写真ウォールフォルダに入った写真を順番に表示。新しく入った写真は優先して出す
自動保存設定は変更の2秒後に自動で保存。次に起動すると同じ状態から始まる

用意するもの

  • Windows のノートPC（グラフィック機能つき。OpenGL 3.3 に対応していること）
  • プロジェクターと、PC につなぐケーブル（HDMI など）。2台以上ならその数だけ
  • スピーカー（音を出す場合）。PC のイヤホン端子や HDMI、オーディオインターフェースから
  • 操作はPC のブラウザ（Edge や Chrome）で行います

④ setup.bat を実行する

setup.bat がうまくいかないとき

setup.bat は、最後に必ず「成功しました」か「失敗：〜」のどちらかを出して止まります。何も出ずに終わることはありません。失敗したときは、出た文字に合わせて直し、もう一度 setup.bat を実行します（入れ終わった部品は飛ばして、続きから入ります）。

出た文字原因と直し方
失敗：Python が見つかりませんPython が入っていない、または「Add python.exe to PATH」のチェック忘れ。①をやり直す。Python を入れた直後は、開いていた黒い画面を閉じてから setup.bat を実行し直す
失敗：部品を入れられませんでしたインターネットにつながっていない（学校や会社のネットワークで止められていることも）。別の回線（スマホのテザリングなど）で試す。それでもだめなら、赤い ERROR の行を写真に撮って相談
（注意）この Python では Spout が使えません失敗ではなく注意です。準備は続きます。Spout を使わないならそのままでかまいません。使うなら Python 3.13 を入れて、setup.bat をやり直す
Microsoft Store が開いたPython が入っていない状態です。Store から入れずに閉じて、①の手順（python.org）で入れる

3起動と画面の見方

run.bat をダブルクリックすると、黒い出力ウィンドウと、ブラウザの操作パネルが開きます。操作パネルが開かないときは、ブラウザで http://localhost:8080/ を開きます。

  • 1上の帯：明るさ・BLACKOUT・マッピング編集・スマホ・セッティング・保存・終了（12章・13章）
  • 2列で再生：真下の列のクリップを全レイヤーで一斉に再生（7章）
  • 3レイヤーの行：1行が1つのレイヤー。左に名前と基本操作、右にクリップ。下の行ほど手前に重なる（6章）。多いときはこの欄だけスクロール
  • 4レイヤー追加（6章）
  • 5タブ：「素材」「レイヤー設定」「ミキサー」「出力」を切り替える。⧉ で別ウィンドウ（下）
  • 6選んでいるタブの中身（この図は「素材」：5章）

上の帯

  • 1VPT39 と状態の表示：再生のしくみ（VLC（音声あり）なら正常）、出力の数、描画の速さ（fps）、「未保存」の有無
  • 2明るさ：全部の出力の明るさ。音量には関係しません
  • 3BLACKOUT (B)：0.5秒で全部の映像を暗くします（暗い間はボタンが黄色く光る）。もう一度押すと戻ります。音は止まりません
  • 4全レイヤー消去：全部のレイヤーをフェードアウトして消します
  • 5マッピング編集 (E)：四隅を調整するモード（オンの間は赤）。本番中は必ずオフ
  • 6スマホ：スマホから四隅を合わせる（オン・オフと QR コード。9章）。オンの間は緑の「スマホ ON」
  • 7セッティング：（名前）：会場・公演ごとの設定ファイル（13章）
  • 8保存（すぐ保存）・終了（確認のあと、保存してアプリを閉じる）

右側のタブと別ウィンドウ

右側は4つのタブで切り替えます。素材（5章・8章）／レイヤー設定（6章・9章）／ミキサー（11章）／出力（4章）。

  • タブの ⧉ を押すか、タブをブラウザのウィンドウの外へドラッグして離すと、その欄が別ウィンドウになります（離した場所に開きます）。素材が多いときは、素材を別ウィンドウにして大きく広げると便利です
  • 別ウィンドウにした欄のタブは「↗」付きで薄くなります。押すと、そのウィンドウが前に出ます
  • 別ウィンドウを閉じる（または「メイン画面に戻す」）と、タブに戻ります

「選択中のレイヤー」

レイヤーの行をクリックすると、そのレイヤーが選択中になり、行の左端がオレンジ色になります。「レイヤー設定」タブとマッピングの図、素材をクリックしたときの追加先は、この選択中のレイヤーです。

4プロジェクターに映す（出力ウィンドウ）

  1. PC とプロジェクターをつなぎ、画面を「拡張」にする
    ⊞Win＋P を押して「拡張」を選びます。「複製」だと手元の画面がそのまま映ってしまいます。
  2. どの画面がプロジェクターか確かめる
    「出力」タブの「画面の配置」にある 識別 を押すと、各画面の真ん中に番号が4秒間出ます。
  3. 出力ウィンドウをプロジェクターの画面へドラッグ
    小さな黒いウィンドウの上の帯（タイトル）をつかんで、プロジェクター側の画面へ移します。
  4. フルスクリーンにする
    「出力」タブの フルスクリーン を押すと、そのウィンドウがある画面いっぱいに広がります。出力ウィンドウ上で F を押すか、ダブルクリックでも同じです。
  5. スクリーンに映ったことを目で確認。操作パネルは手元のPC 画面に置いたままにします。
  • 1＋出力を追加：出力2、出力3…を増やす（上限なし）
  • 2出力の名前・解像度・いまある画面（画面1 がメイン）
  • 3フルスクリーン：押すたびにオン／オフ。オンのときは枠なし・最前面・マウスカーソル非表示
  • 4手元に戻す：ウィンドウに戻して、メイン画面の真ん中へ（見失ったとき用）
  • 5✕：その出力を削除（出力が2つ以上のとき。そこに映していたレイヤーは出力1へ移る）
  • 6映すレイヤー：この出力に映すレイヤーにチェック。グレーで押せないのは「そのレイヤーの出力はここだけ」の印
  • 7横長につないだ画面の名前と大きさ
  • 8横長にするチェック、重なり、そのつなぎ目のガンマ（下）
  • 9識別／ディスプレイ設定…（Windows の設定を開く）
  • 10画面の配置図：つながっている画面の並び・解像度・拡大率。緑の枠＝出力ウィンドウがある画面
  • 11本番の解像度：本番のプロジェクターの解像度（下）

プロジェクターが2台以上のとき

使い方は2とおりあります。

使い方やり方
それぞれ別の映像＋出力を追加 で出力2を出し、2台目の画面でフルスクリーン。映すレイヤーは「映すレイヤー」（⑥）か、「レイヤー設定」タブの「映す出力」で選ぶ
同じ映像を両方に1つのレイヤーを両方の出力にチェック。同じ映像が同じタイミングで出る。位置合わせ（四隅）は出力ごと（9章）。音は1回だけ鳴る
2台で1枚の横長下の「横長の画面」

横長の画面（2台のプロジェクターで1枚の映像）

  1. 出力を2つ用意し、左のプロジェクターに出力1（例では出力2）、右に出力2（例では出力3）をフルスクリーンにする
  2. 右側の出力の「出力○の右につなげて横長にする」（⑧）にチェック。2つが1枚の横長の画面（例：1920＋1920）になり、名前が「出力2＋出力3（横長）」になる
  3. レイヤーをこの横長の画面に映し、四隅を横長の画面いっぱいに合わせる
  4. プロジェクターの映像を少し重ねて設置したときは、「重なり」に重なっている幅（px）を入れる。重なり部分は両方に同じ映像が出て、なめらかにぼかしてつながる
  5. 重なりが周りより明るい・暗いときは、その出力の行の「ガンマ」（⑧）を調整する（明るすぎる→大きく、暗すぎる→小さく。ふつうは 2.2）。ガンマはつなぎ目ごとなので、3台以上つないだときは、つなぎ目ごとに合わせられる
ポイント左右のプロジェクターは同じ解像度にします。3台以上もつなげられます（出力4を「出力3の右につなげる」）。つないだ右側の出力には「映すレイヤー」は出ません（横長の画面にまとめて映すため）。
覚えているフルスクリーンにした画面は保存されます。次の起動でも、位置と解像度が同じ画面にフルスクリーンで開きます。画面がない・並びが変わったときは、ウィンドウで開いて警告を出します。
本番の解像度（⑪）本番で使うプロジェクターの解像度（1920×1080 など）を選んでおくと、ウィンドウの大きさに関係なく、いつもその大きさで描きます。別のPCで小さいウィンドウのまま合わせても、本番でそのまま使えます（形が違うときは黒い帯付きで縮小表示）。「自動」はウィンドウの大きさで描きます。
× では閉じない・拡大率は 100%出力ウィンドウは右上の × では閉じません（減らすときは「出力」タブの ✕）。プロジェクターの画面は Windows の「拡大縮小」を 100% にし、画面の並びの変更はリハの前に。

パソコンから取り込む・消す

パソコンから取り込むエクスプローラーから動画や画像を、操作パネルの「素材」の欄へドラッグして離すと、media フォルダにコピーされます（緑の点線が出たら離す。何個でも一度に）。フォルダで絞り込んでいるときは、そのフォルダに入ります。同じ名前があると「名前 (2)」で保存します。動画・画像でないファイルは飛ばします。素材を消すときは、タイルにマウスを乗せて右上の ✕（ごみ箱へ移る）。

並べ替えとコピー

  • クリップのサムネイルをドラッグすると、同じレイヤーの中で並べ替えられます（落とす位置に黄色い線が出る）
  • 別のレイヤーへドラッグすると、そのレイヤーにコピーされます（終了時の動きは「ループ」に戻る）
  • 曲ごとに列をそろえる：曲1の映像はどのレイヤーでも1番目、曲2は2番目…と並べると、「列で再生」の1回で全レイヤーが切り替わります。映さないレイヤーには空白を置きます

ミニ操作（サムネイルの下）

切り替えのしくみ（クロスフェード）

クリップを押すと、前の映像が薄くなりながら、次の映像が濃くなって入れ替わります。音も同時に入れ替わります。かかる秒数はレイヤーの「フェード」です。

途切れない次の動画の最初の映像が出るまで（最大3秒ほど）は、前の動画の映像と音を流し続けます。ファイルが消えた・壊れている動画は切り替えずに前の映像のまま、行の左に赤字で知らせます。

レイヤーの映像（同じ映像を、別の場所・別の出力に）

あるレイヤーの今の映像そのものを、別のレイヤーの素材として使います。元のレイヤーでクリップを切り替えると、こちらも同じタイミングで切り替わります。

  • 例：L1「背景動画」の映像を、L3 で出力2にも映す（L3 は L1 と別の位置・別の形に合わせられる）
  • 元のレイヤーを「表示」オフにしても使えます（素材としてだけ使う）
  • 音は元のレイヤーで鳴ります（二重になりません）。自分自身の映像は使えません
  • 単に「同じレイヤーを2つの出力に」なら、「映す出力」で両方にチェックするほうが簡単です（6章）

カメラ・キャプチャーボード（別のPCの画面と音）

  1. キャプチャーボード（HDMI→USB など）やカメラをPC につなぎ、「一覧を更新」
  2. 一覧の機器をレイヤーに追加し、クリップを押すと映像が映る（遅れはおよそ 0.1〜0.2 秒）
  3. 音も流すときは、クリップの「音声なし」の欄で音声入力を選ぶ（キャプチャーボードなら、たいてい同じ名前が入った「デジタル オーディオ インターフェイス」など）。音量はミキサーのそのレイヤーで
ポイント再生中に音声入力を選び直すと、映像は止めずに音だけ入れ替わります。音は Windows の「既定のスピーカー」から出ます。OBS の仮想カメラも一覧に出るので、OBS で作った画面も取り込めます。
同じ機種を2台同じ機種のキャプチャーボードを2台つなぐと、2台目は「名前（2台目）」と出ます。抜き差しや再起動で1台目と2台目が入れ替わることがあるので、いつも同じ USB の差し込み口につなぎます。
途中で抜けたら映っていたカメラのケーブルが抜けたり電源が切れたりすると、最後の映像のまま、行の左に赤字で「カメラの映像が止まっています」と出て、5秒ごとに自動でつなぎ直します。つながると赤字は消えます。
同じカメラは1か所だけ同じカメラを2つのクリップで同時には開けません（赤字で知らせます）。同じカメラの映像を別の場所にも映すときは「レイヤーの映像」を使います。

ウィンドウ取り込み（同じPCの別のアプリ）

Zoom・Discord・ブラウザなど、どのウィンドウでも映像を取り込めます。音は取り込みません。

  • ウィンドウは最小化しないでください（止まることがあります）。ほかのウィンドウの後ろに隠れていても取り込めます
  • 題名が変わるアプリ（再生中の曲名が出るなど）でも、だいたい同じ題名のウィンドウを探します
  • 動画配信サービスなど、保護された映像は黒くなることがあります

Spout（ほかの映像アプリから受け取る）

Spout は、Windows のアプリ同士で映像を受け渡すしくみです（Mac の Syphon にあたる）。映像をグラフィックボードの中で直接渡すので遅れがほとんどなく、透明な部分もそのまま重ねられます。送る側のアプリが Spout に対応している必要があります。

Processing で作った映像を映す（Spout for Processing）

  1. ライブラリを入れる：Processing のメニュー「スケッチ」→「ライブラリをインポート」→「ライブラリを追加…」。検索欄に Spout と入れ、「Spout for Processing」を選んで「Install」。1回だけでよい
  2. スケッチに3か所書き足す（下の例）：① いちばん上で import spout.*; ② setup() で Spout を作って名前を付ける ③ draw() の最後で spout.sendTexture();
  3. size() は P2D か P3D にする。size(1280, 720) のまま（JAVA2D）だと送れません
  4. 実行（▶）する。VPT39 で「一覧を更新」すると、Spout の欄に付けた名前（例：Processing）が出る
// ① Spout を使う
import spout.*;
Spout spout;

void setup() {
  size(1280, 720, P2D);            // P2D か P3D（OpenGL）にする
  spout = new Spout(this);         // ② 作って
  spout.setSenderName("Processing"); //    VPT39 の一覧に出る名前
}

void draw() {
  background(0);
  fill(255, 120, 200);
  ellipse(mouseX, mouseY, 160, 160);
  spout.sendTexture();             // ③ いま描いた画面を送る（draw の最後）
}
したいこと書き方
背景を透明にして重ねるbackground(0); の代わりに clear();。描いた所だけが VPT39 の上のレイヤーに重なる（VPT39 側の合成は「通常」）
解像度size() の大きさがそのまま送られる。投影する大きさ（例：1920, 1080）にすると、きれいに映る
2つ以上送るスケッチごとに別の名前を付ける（同じ名前だと後から動かした方だけになる）
止めるスケッチを止めると、VPT39 は最後の映像のまま赤字で知らせる
一覧に出ないとき① スケッチが実行中か ② size() が P2D／P3D か ③ draw() の中で sendTexture() を呼んでいるか ④「一覧を更新」を押したか。ノートPCで映らないときは、Windows の「設定 → ディスプレイ → グラフィック」で、Processing（java.exe）と VPT39（python.exe）の両方を「高パフォーマンス」にして、同じグラフィックボードで動かします。
Mac ではMac の Processing には同じ使い方の「Syphon」ライブラリがあります。VPT39 は Windows 専用なので、受け取れるのは Spout です。

9マッピング（形を合わせる）

プロジェクターを斜めから当てたり、台形のスクリーンに映したりすると、映像の形がずれます。レイヤーごとに四隅を動かして、スクリーンの形に合わせます。

  1. レイヤーの行をクリックして選ぶ（左端がオレンジになる）。「レイヤー設定」タブを開く
  2. 上の帯の マッピング編集 (E) をオン（または E）。出力ウィンドウにレイヤーの枠と四隅の点、下に操作の案内が出ます。テスト表示 をオンにすると格子・対角線・円が映り、ゆがみが分かりやすくなります
  3. 図で角をドラッグして、スクリーンの角に合わせる。内側をドラッグすると全体が移動します
  4. 最後に矢印キーで微調整：⑥ で角（または全体）を選び、矢印キーで 1px ずつ（下の表）。スクリーンの前で合わせるならスマホから（次のページ）
  • 1編集 (E)／テスト表示／四隅リセット（画面いっぱいの四角に戻す）
  • 2位置合わせする出力：複数の出力に映しているレイヤーのとき、どの出力の四隅を直すか選ぶ（出力ウィンドウ上で角をつかんでも切り替わる）
  • 3図：その出力に映しているレイヤーが出る（選択中以外は薄く）。白い四角が動かせる角
  • 4選んでいる角（赤）。ほかの角は黄色。「全体」を選んでいるときは、案内に ALL と出る
  • 5案内：編集中のレイヤーと出力、操作キー（編集中だけ出る）
  • 6矢印キーで動かす所：左上／右上／右下／左下／全体（緑が選択中）。全体は形を変えずに位置だけずらす

スマホで位置合わせ（セッティングモード）

PC から離れて、スクリーンの前や客席でスマホを持って四隅を合わせられます。スマホで操作している間、スクリーンの映像そのものに黄色い枠と赤い印（いま動かしている所）が出るので、スクリーンを見たまま十字ボタンを押すだけで合わせられます。

  • 1枠を表示：スクリーンに枠と印を出す（PC の「マッピング編集」と同じ）。スマホで開くと自動でオン。合わせ終わったら必ずオフ。左上の丸が緑ならつながっている
  • 2レイヤーと、複数の出力に映しているときは出力を選ぶ（PC の選択も変わる）
  • 3配置図：角を指でなぞると変形、内側をなぞると移動（だいたいの位置まで）
  • 4動かす所：左上・右上・左下・右下・全体（緑が選択中）
  • 5十字ボタン：押すと 1回分、長押しで続けて動く（1.5秒たつと速くなる）。真ん中で 1px／10px を切り替え
  • 61つ戻す（続けて動かした分はまとめて1回）・テスト模様（格子。オンの間は赤）・四隅リセット（確認あり。1つ戻すで戻せる）
  • 7不透明度・ぼかし

つなぎ方（QR コード）

  1. 上の帯の「スマホ」を押し、「スマホから操作する」（①）。起動し直す必要はありません。初めてのときに「Windows セキュリティの重要な警告」が出たら、「プライベート ネットワーク」にチェックして「アクセスを許可する」
  2. PC とスマホを同じ Wi-Fi につなぎ、スマホのカメラで QR コード（②）を読み取る。位置合わせの画面が開く（下にアドレスも出るので、入力してもよい）
  3. 終わったら「スマホからの操作をやめる」。オン・オフは保存され、次の起動でも同じ。Wi-Fi を変えたときは「アドレスを調べ直す」（③）
気をつけること合言葉がないので、同じ Wi-Fi の人なら誰でも操作できます。自分のルーターか、スマホのテザリングで使います。会場やホテルの Wi-Fi は、機器どうしの通信を止めていることが多く、つながらないことがあります。使わないときは「スマホからの操作をやめる」を押します。
画面が消えないようにスマホの「自動ロック」を長め（5分など）にしておきます。つながらなくなると、スマホの上に赤く「PCとつながっていません」と出て、ボタンが押せなくなります（つながると自動で戻る）。

10写真ウォール

指定したフォルダに入った写真を、順番に表示するレイヤーです。会場で撮った写真や、来場者から集めた写真を流すのに使います。

  • 1写真ウォールの行（名前と「表示」など。音はないので M はない）
  • 2並べた画像：押すとその画像をすぐ出す（緑の枠＝いま出している）。ドラッグで並べ替え、✕ で外す
  • 3素材の画像をここへドラッグして並べる
  • 4写真の枚数・間隔と、次の写真 ▶（すぐ次へ）

出す写真の決め方（2とおり）

やり方出し方

フォルダの写真（行が空のとき）「フォルダ」に入っている写真を順番に出す（今までどおり）。新しく入った写真を優先できる

どちらも列で再生とは別に、「間隔」と「切り替え方」に合わせて動きます。写真ウォールに入れられるのは画像だけです（動画・カメラなどは動画レイヤーへ）。

設定（写真ウォールの行を選んで「レイヤー設定」タブ）

設定内容
フォルダ行に画像を並べていないときに、写真を読むフォルダ。「photos」のように書くと VPT39 フォルダの中、フルパスでほかの場所も指定できる。名前を間違えると空のフォルダが新しく作られ「0枚」になるので、枚数を確認
間隔(秒)次の写真に切り替えるまでの秒数。0 なら自動では切り替えない
切り替え方フェード（じわっと）／静止（効果なし・パッと切り替え）／スライド（右から左・左から右・下から上・上から下）／ワイプ（左から順に）／ズーム（少し寄りから）。かける時間は「フェード」の秒数。スライドは前の写真を押し出す。切り替えの途中は次の写真を出さない（間隔より切り替え時間が長いと、そのぶん間隔が延びる）
白フチ写真のまわりの白い枠の太さ
新着を優先して表示新しく入った写真を先に出す（前の切り替えから最短3秒）。間隔が 0 でも、新着だけは自動で出る
  • 写真は縦長・横長のまま、歪まずに収まります（マッピングの四角の形に合わせて自動で調整）
  • 書き込み途中の写真を避けるため、保存されてから1秒待ってから読み込みます
  • 読むのはフォルダのすぐ下の png・jpg・bmp・gif・webp だけ（サブフォルダの中や、iPhone の HEIC 写真は出ない）。動くGIF・APNG・WebP は動く

運用の注意写真ウォールは、そのフォルダに入った写真をすべて映します。人の目で確認して OK になった写真だけが入るフォルダ（例：Dropbox の「承認済み」フォルダ）を指定してください。写っている人の掲載の同意にも気をつけます。

11音声ミキサー

動画レイヤーとカメラの音は、どの出力に映していても全部同時に鳴ります。音量は「ミキサー」タブで調整します。

  • 1音声マスター：全体の音量
  • 2出力ごと：その出力に映しているレイヤー全部の音量（複数の出力に映すレイヤーは1つ目の出力のところ）
  • 3レイヤーごと：そのレイヤーの音量。下の緑のバーは、その音量で鳴らしている目安（クロスフェード中は上下する）
  • 4M：ミュート。赤くなったら消音中

実際の音量は レイヤー × 出力 × 音声マスター の掛け算です。どれか1つでも 0 か M（ミュート）なら、その音は消えます。写真ウォールには音がないので、ミキサーには出ません。レイヤーの映像・ウィンドウ・空白のクリップは音を出しません。

止まらない音映像の BLACKOUT や「表示」オフでは音は止まりません（ライブ中に音楽が途切れないように）。音を止めるのは M かフェーダーです。

音が出ないとき（上から順に）

  1. PC の音量（タスクバーのスピーカー）が 0 やミュートになっていないか
  2. Windows の音の出力先が、つないだスピーカーになっているか
  3. ミキサーの M が赤くないか、フェーダーが左端になっていないか
  4. 操作パネル左上が「VLC（音声あり）」か（「音量は全レイヤー共通」と出たら、レイヤーごとの音量が効かない状態）
  5. 動画ファイル自体に音が入っているか。カメラなら、クリップの音声入力が「音声なし」になっていないか

本番中にすること

  • 曲が変わったら 列で再生、1つだけ変えたいときはサムネイルをクリック
  • L1 を順番に進めるだけなら Space

アプリが落ちたとき

  1. プロジェクターのリモコンの AV ミュート（映像ミュート）で、客席にデスクトップが映らないようにする
  2. run.bat をダブルクリック
  3. 全部の出力が元の画面にフルスクリーンで出るのを待つ（出ないものは4章の手順で）
  4. クリップを押し直す（並び・形・音量は保存されている。再生位置は戻らない）

  • 終了 を押すと、確認のあと保存して閉じます

  • 保存されないもの：その時の再生位置、BLACKOUT の状態（起動時はいつもオフ）、テスト表示（起動時はいつもオフ）

セッティング（会場・公演ごとの設定ファイル）

会場や公演ごとに、曲順・クリップ・レイヤー・マッピング・音量・出力の設定をまとめて、名前を付けて保存しておけます。上の帯の「セッティング：（名前）」を押すと、窓が開きます。

  • 1名前を付けて保存：名前を入れて保存（Enter でも）。同じ名前があれば、上書きしてよいか確認
  • 2いま開いているセッティング（緑の枠）。変えると2秒後に自動で上書き保存
  • 3開く：確認のあと、そのセッティングに切り替わる
  • 4複製：いま開いているものを元に、新しい名前で保存（会場違いの版を作るとき）
  • 5✕：ごみ箱へ（確認あり・ごみ箱から戻せる）
  • ファイルは VPT39\settings フォルダに「名前.json」で入ります。Dropbox で同期すれば、別のPCでも同じ一覧が使えます（人に渡すときは、そのファイルを相手の settings に入れてもらう）

  • 別のPCで準備するときは、出力ごとの「本番の解像度」（4章）を本番のプロジェクターに合わせておくと、四隅や重なりがそのまま本番で使えます
